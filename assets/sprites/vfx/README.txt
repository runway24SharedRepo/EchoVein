Echo Vein Explosion VFX Pack v1

Contents:
- 20 transparent PNG sprites for explosion / impact visual effects.
- 1 preview sheet.

Suggested usage:
- Use these sprites as layered VFX frames, impact decals, or quick additive flashes.
- Combine 2-4 sprites at different scales and lifetimes for richer explosions.
- Recommended blend behavior in canvas:
  1. Draw core flash first
  2. Draw fireball / fragment burst second
  3. Draw shockwave / ring blast on top
  4. Draw smoke bloom last with a slower fade
