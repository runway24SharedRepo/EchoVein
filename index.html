⛏️ Rockfall Survivor

A modular HTML roguelike survivor prototype inspired by cave-mining auto-shooters. It has procedural destructible caves, minerals, auto weapons, XP gems, upgrades, swarms, elites, and extraction-style survival.

Goal: survive as long as possible. The game escalates every minute. Enemies drop XP; minerals give economy. Drilling is useful but overheating slows excavation.

Level Up - Choose an Upgrade

Pick one upgrade. Weapon stacks are intentionally strong, because roguelike survivor games should become chaotic.
